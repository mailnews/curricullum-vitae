# Website CV Abdul Azis

Website CV responsif dengan HTML, CSS, dan JavaScript murni.

## File
- `index.html` — konten CV
- `style.css` — tampilan responsif hitam-putih dengan aksen hijau
- `script.js` — menu navigasi mobile dan tahun otomatis
- `foto-abdul-azis.jpg` — foto profil yang ditampilkan di bagian header

## Cara melihat
Buka `index.html` di browser.

## Publikasikan dengan GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah ketiga file website ini ke root repository.
3. Buka **Settings → Pages**.
4. Pada bagian Build and deployment, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.

Catatan: detail nomor sertifikat dan tahun pelatihan bisa ditambahkan setelah tersedia.
